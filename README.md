# 📝 To-Do List

Projeto de lista de tarefas desenvolvido com **HTML, CSS e JavaScript puro**.

## 🚀 Funcionalidades

- ✔️ Adicionar tarefas
- ✔️ Editar tarefas
- ✔️ Remover tarefas
- ✔️ Marcar como concluída
- ✔️ Filtro (todas, concluídas, pendentes)
- ✔️ Persistência com LocalStorage

## 💻 Tecnologias utilizadas

- HTML
- CSS (Flexbox)
- JavaScript (DOM, eventos, lógica)
